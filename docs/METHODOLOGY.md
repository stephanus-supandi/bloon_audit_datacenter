# Methodology

1. Identify the exact project and facility; do not conflate campus-level and building-level information.
2. Register each source with issuer, title, URL, access date, what it establishes, and what remains unknown.
3. Link each finding to registered evidence IDs.
4. Separate source statements from analyst observations and inference.
5. Use `unverified` when evidence is insufficient and `undetermined` severity when impact cannot be assessed.
6. Treat missing public documents as research gaps, not proof of technical failure or regulatory breach.
7. Re-run tests after changes and retain actual logs. Never report tests as passing unless they were run.
